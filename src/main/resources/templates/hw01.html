- JPA (Java Persistence API) là một tiêu chuẩn của Java EE dùng để quản lý dữ liệu giữa ứng dụng Java và cơ sở dữ liệu quan hệ. Nó định nghĩa tập hợp các interface và quy tắc để thao tác dữ liệu mà không phụ thuộc vào một framework cụ thể. - Hibernate là một hiện thực (implementation) phổ biến nhất của JPA, cung cấp đầy đủ các tính năng JPA cùng nhiều chức năng mở rộng mạnh mẽ => Sử dụng JPA giúp lập trình viên tập trung vào logic nghiệp vụ, không phải viết SQL thuần hoặc xử lý kết nối JDBC phức tạp, từ đó tăng tốc độ phát triển ứng dụng, dễ bảo trì và dễ mở rộng. Nói ngắn gọn, JPA giống như “luật chơi” còn Hibernate là “người chơi chuyên nghiệp” thực thi luật đó trong dự án Java hiện đại.
